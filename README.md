# Jersey Collision tools

Reconciliation, estimate comparison and job tracking tools for Jersey Collision, built by Reliable Office Services.
Open this folder in Claude Code and start with `CLAUDE.md`.

- Live reconciliation: https://vendor-invoice-reconciliation.vercel.app
- Run the checks: `npm install && npm test && npm run test:dist`
- Deploy (protected build only): `npm run deploy`
